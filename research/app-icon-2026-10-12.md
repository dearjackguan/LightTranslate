# LightTranslate 1.2.1 application icon

## Design and implementation

The requested icon refinement replaces the default WinForms application symbol with an original translation mark: a cobalt blue rounded square, white Chinese `文` and Latin `A`, and mint bidirectional arrows. Colors are `#1E57CD`, `#FFFFFF` and `#8DECE2`. It matches the existing application accent and remains identifiable on light and dark surfaces.

Source assets are `assets/app-icon.svg`, `assets/app-icon.png` and `assets/app.ico`. The SVG contains glyph outlines rather than font references. `scripts/prepare-app-icon.ps1` uses installed Microsoft YaHei UI and Segoe UI with System.Drawing to generate the same geometry and supersampled PNG exports; no package or external artwork was added. The ICO contains 16, 20, 24, 32, 40, 48, 64, 96, 128 and 256 pixel frames, with 32-bit DIB frames and a compressed PNG frame at 256 pixels.

Both the Windows executable icon group and the managed window resource embed the ICO. MainForm loads its icon from the managed resource, so relocating the executable with its normal offline bundle does not require a separate icon file. Both build and verification compilation include the icon resources. The application was gracefully closed and restarted with version 1.2.1.0. Translation-worker algorithms, OCR behavior and model weights were not edited in this visual patch.
